Logreader v0.8 - corresponding source locations

Logreader's matching application source and build files are included in
source/Logreader-v0.8-source.zip. The same source ZIP is a release asset.
Its BUILD.txt identifies the Python version and build commands; pinned
Python package versions are in packaging/windows-x64/build-constraints.txt.

The upstream components below are distributed without project modifications.
Their exact-version source archives include their build scripts and notices.
Qt sources include the third-party code embedded in the respective modules.
These locations were checked when preparing this release on 2026-10-14.
